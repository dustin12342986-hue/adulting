HOW THE TWO PROVIDERS SPLIT
  Anthropic is tried FIRST, because it's the only one that supports this app's
  tools — the things that let Blue Bonnet actually add a bill, build a budget
  or log transactions instead of just talking about them.

  If that call fails for ANY reason (out of credit, rate limited, Worker down,
  offline), the same question is retried on your gateway automatically. The
  reply still arrives, labelled:

    "Brain building mode — this one ran on your own gateway, which is what
     trains it over time. I can talk things through here, but I can't change
     anything in the app until the main line is back."

  So you're never stuck without an assistant, and it never pretends to have
  done something it couldn't.

  Statement extraction works the same way: Anthropic first, gateway if that
  fails, and the toast says "brain building mode" when the backup was used.

THUMBS UP / DOWN
  Small and grey under each reply, no colour until you press one, no prompting.
  On gateway replies the rating goes back as training data. On Anthropic
  replies it's kept locally so it isn't thrown away.
