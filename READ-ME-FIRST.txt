WHY IT LOOKED LIKE IT DIED
  Progress was shown with a toast, and toasts clear themselves after about
  three seconds. Each part of a statement takes longer than that, so the
  message vanished mid-request and the import looked like it had stopped.
  It probably hadn't.

NOW WHILE IT READS
  A panel stays on screen until the work is actually done, showing:
    - which part it's on, out of how many
    - a progress bar and percentage
    - how many transactions it's found so far
    - time remaining, based on how long the finished parts actually took

  If a request fails you get a real explanation with the status code — 401/403
  means the Worker's API key, 429 means rate-limited, 404 means the Worker
  Proxy URL in Settings is wrong. Parts that succeed are still imported.

HOW TO USE IT
  Budget -> Statements -> "Upload statement", pick the PDF, wait for the bar.
  The paperclip in the Blue Bonnet chat is for asking about a receipt or a
  single charge — the upload button is what fills in your Budget tab.
